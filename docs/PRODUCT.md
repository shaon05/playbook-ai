# Product

PlayBook AI is a private, media-first reading companion: users upload a document, receive a short AI narration preview, listen on mobile, and resume later.

The core journey is login → upload → extract → understand → generate audio → listen → remember → continue. The first usable MVP is authentication, library, PDF upload, extraction, chapter detection, voice selection, short preview generation, playback, progress, and resume.

Phase 1 in this repository is the visual mobile shell only. Its books, progress, and processing states are explicitly demo data and are not connected to a backend yet.
