# Design system

The mobile shell uses a dark-first, audio-media visual language. Tokens live in `src/constants/theme.ts`.

Colors: background `#090A0D`, surface `#12141A`, elevated `#191C23`, text `#F8F9FB`, secondary text `#9DA4B2`, violet accent `#7C5CFC`, teal accent `#2DD4BF`.

Spacing uses 4/8/12/16/20/24/32/40/48. Radii are 10/14/16/24/pill. Use artwork-led cards, large touch targets, safe areas, concise loading states, and a persistent mini player. Avoid excessive gradients, borders, nested cards, and dashboard-like clutter.
